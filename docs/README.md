# Documentação - Guilda da Forja

Bem-vindo à documentação oficial do ecossistema e dos personagens da **Guilda da Forja** (*Forja dos Narradores*).

Esta pasta reúne as fichas conceituais, traços de personalidade, arquétipos de fantasia e sugestões de comandos/interações para cada integrante da nossa guilda de bots.
