# guilda-da-forja
Um monorepo (com Nx) de todos os bots da Forja dos Narradores. Os bots utilizam NodeJS com TypeScript, consumindo a biblioteca do DiscordJS, além de RabbitMQ, Docker, e Lavalink v4.
